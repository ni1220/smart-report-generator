# 智匯數據簡報神器 — 需求規格

## 1. 業務需求

### 1.1 核心目標
- 自動讀取 1-12 月信用卡業務統計資料（Excel 格式）
- 透過 AI 進行策略顧問級商業洞察分析
- 產出 16 頁原生可編輯簡報 + 同步 Excel 資料檔
- 自動寄送報告至指定收件人

### 1.2 使用者故事
- 作為金控分析師，我想要上傳統計資料後自動獲得一份策略分析報告，以便快速掌握市場動態
- 作為主管，我想要收到可直接編輯的簡報，以便根據需求調整內容進行彙報
- 作為團隊成員，我想要透過語音描述需求就能生成客製化報告

### 1.3 關鍵約束
- PPT 圖表必須為原生可編輯向量物件，絕對禁止貼圖片
- Excel 圖表必須為原生 openpyxl chart 物件
- 簡報恰好 16 頁
- 部署於 AWS us-east-1 區域
- Amazon Bedrock 請求頻率 ≤ 1 RPS

## 2. 功能需求

### FR-01: 資料解析
- 支援讀取多工作表 Excel 檔案
- 自動識別欄位並進行資料驗證
- 計算跨表加總、市佔率、活卡率等衍生指標

### FR-02: AI 洞察生成
- 分段生成：大綱 → 逐頁洞察 → 一致性審核
- 洞察必須包含驅動因素分析，非流水帳描述
- 輸出結構化 JSON，含圖表類型與繪圖數據

### FR-03: 簡報生成
- 載入品牌模板
- 原生向量圖表渲染
- 支援多種版面配置（封面、圖表頁、雙欄頁等）

### FR-04: 品質檢驗
- 頁數驗證（恰好 16 頁）
- 圖表存在性檢查
- 無圖片圖表檢查
- 文字完整性檢查
- Excel-PPT 數據一致性

### FR-05: 自動寄發
- 透過 SES 寄送含附件的 HTML 信件
- 提供 Presigned URL 下載連結

### FR-06 (加分): 語音驅動
- 接收音訊檔案
- 語音轉文字（Amazon Transcribe）
- 意圖提取並動態客製化報告

## 3. 非功能需求

### NFR-01: 效能
- 端到端生成時間 < 3 分鐘

### NFR-02: 安全
- Cognito JWT 身份驗證
- S3 SSE-KMS 加密
- Block Public Access
- 最小權限 IAM

### NFR-03: 可觀測性
- CloudWatch Dashboard
- X-Ray 分散式追蹤
- 失敗告警 (SNS)

### NFR-04: 可靠性
- Step Functions 自動重試
- 品質閘門 + 最多 2 次重試
- DLQ 處理失敗任務
